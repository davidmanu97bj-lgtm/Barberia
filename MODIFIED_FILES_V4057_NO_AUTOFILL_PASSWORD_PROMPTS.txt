EXPLORA v4057 · Evitar carteles de contraseñas precargadas

Archivos modificados:
- index.html
- service-worker.js
- js/segments/11-script.mjs
- css/segments/01-style.css
- css/segments/50-style.css

Cambios aplicados:
1. El login deja de usar input type=password para evitar que iOS/Safari lo detecte como contraseña guardada.
2. La clave sigue viéndose oculta con -webkit-text-security: disc.
3. El botón Ver/Ocultar ahora alterna la máscara visual, no el tipo real del input.
4. Se desactivó autocomplete/autocorrect/spellcheck en usuario y contraseña.
5. Se agregaron flags para gestores externos: data-lpignore, data-1p-ignore y data-bwignore.
6. El campo de contraseña al crear chofer también deja de activar gestores de contraseñas.
7. Al iniciar sesión correctamente se limpia el valor de contraseña en pantalla.
8. Se actualizó cache/versionado para que iOS/Android no usen HTML/JS/CSS viejo.

Nota técnica:
Ninguna web puede prohibir al 100% que iOS muestre sugerencias del sistema si el usuario tiene llavero/autorrelleno muy agresivo, pero esta corrección evita el disparador principal: input type=password + autocomplete current-password.

No se tocaron cálculos, Firestore, WhatsApp, cierres, histórico ni reglas financieras.
